# 聖經問答 v8 - 全66卷四選一經文填空「自動生成初稿」

此壓縮檔完全平面、所有 .js 和 HTML 放在同一層，直接取代 GitHub bible 專案根目錄對應檔案。

## 題庫範圍
- 66卷 × 每卷簡單、普通、困難、上天堂各30題 = 7,920題
- 所有正確填空用字皆擷取自使用者提供之《新標點和合本》全本 PDF，附精確經節。
- 不使用網路解經或其他譯本。
- 題目由程式依經文抽取詞語產生，**不是7,920題獨立人工編寫的人物故事、歷史細節題**，也**尚未逐題人工核對語意和難度**。
- 四級難度目前主要依遮蔽字數、上下文提示長度及干擾選項接近度區分，需後續人工編修才能達到真正的「上天堂」魔王題難度。
- **建議先測試，審閱後再用於正式競賽**。

## 上傳方式
1. 先備份你 GitHub 原本的檔案。
2. 解壓縮後，不建立任何資料夾，直接把檔案全部上傳至 GitHub repository 根目錄；同名選覆蓋。
3. 確認 HTML 載入 ./styles.css 與 ./screen.js，模組 ./questions.js 與 ./genesis.js 等都在同一層。
4. 到 GitHub Pages 網站重新整理，選一卷一個難度試玩。

## v10 新增：OX 走位搶答
- 主機建立房間，玩家掃 QR Code 後加入。
- 手機陀螺儀左右傾斜控制主機畫面的小人物。
- 每題 8 秒，小人物從中央出發；左／右分別是 O 與 X。
- 約 30% 題目會在「題目開始前」把 O、X 左右互換；作答中不會突然換邊。
- 手機只在方向改變時寫入 left/right/stop，主機自行平滑移動人物，降低 Firebase 流量。
- 若手機瀏覽器無法取得動作感應權限，可使用手機頁面的左移／停止／右移備援按鈕。

## v11：⭕❌ 九宮格答題戰
- A隊 = ⭕、B隊 = ❌。
- 每個正式回合，系統從該隊在線玩家中隨機抽 1 人選擇九宮格空格。
- 選格後，由進攻隊先回答 A/B/C/D；該隊第一個送出的答案會被採用。
- 進攻隊答對：取得該格，正式回合換到對方。
- 進攻隊答錯：另一隊可接答同一題。
- 接答成功：接答隊取得該格，而且下一個正式回合仍由接答隊進攻。
- 雙方都答錯：該格保持空白，之後可再次進攻；下一正式回合由原進攻隊的對手開始。
- 任一隊橫、直、斜三格連線即獲勝。
- 九格填滿仍無三連線：進入搶答決勝。最快搶到的玩家先回答；答錯則直接交給另一隊回答同一題。
- 九宮格模式需 A、B 兩隊至少各 1 位玩家。

## v13：⛓️ 鎖鏈逃脫
- 新增獨立多人動作小遊戲，不需要題庫。
- 主機建立房間後，玩家掃 QR Code 加入；至少 1 人即可開始。
- 遊戲 45 秒。玩家左右傾斜手機控制大螢幕上的角色移動。
- 敵方鎖鏈會先警告「左側／中央／右側」，約 0.9 秒後攻擊該區域。
- 沒被打中的玩家每次攻擊 +10 分。
- 被擊中的玩家會被鎖住，暫時不能移動；手機顯示掙脫進度。
- 玩家快速左右甩動手機累積 8 次有效動作即可掙脫，成功掙脫 +5 分。
- 若手機無法提供動作感應，可使用「快速點擊掙脫」備用按鈕。
- 遊戲結束依總分排行。
- 建議玩家握緊手機、留意周遭空間，不需要用力揮甩身體。


## v14：💨 極限閃避
- 新增多人動作淘汰遊戲，不使用題庫。
- 玩家掃 QR Code 加入，大螢幕會顯示迎面而來的障礙與閃避方向。
- 五種動作：左、右、上、下、跳。
- 手機以方向感應判斷上下左右傾斜；跳躍使用動作感應的加速度變化判斷。
- 每一波在期限內完成正確動作即過關；錯誤或沒有完成就出局。
- 成功閃避每回合基本 +100 分，另加回合加成。
- 回合越後面反應時間越短：由約 2.4 秒逐步加速到約 0.95 秒。
- 最多 30 回合；全部出局或 30 回合結束後依分數排名。
- 手機感應不支援時，保留方向／跳躍按鈕作為備用。
- 為安全起見，「跳」只需小幅度動作讓手機感應到加速度，不需要高跳或大幅甩動。

## v16：✍️⚔️ 字戰 PK
- 兩人網路 PK，需剛好 2 位玩家加入。
- 每人先選屬性：藍、紅、綠、黑、黃。
- 開始後兩人同時有 15 秒沿著字的半透明模板描寫。
- 描在線內會提高「完整度／戰力」，寫到模板外會降低準確度與戰力。
- 最終戰力：以 100 為基準，完整度提高、越界比例降低；限制約 20～200。
- 攻擊倍率再乘「完整度」。例如黑色基礎攻擊 1.5×，完整度 90% 時實際為 1.35×。
- 一般相剋暫採循環：藍剋紅、紅剋綠、綠剋藍；剋屬攻擊 1.4×，反向 0.8×；其他一般組合 1×。
- 黑色對藍／紅／綠：攻擊 1.5×，同時也承受對方 1.5×；黑對黑雙方 1.5×；黑對黃 1.4×、黃對黑 1.5×。
- 黃色對藍／紅／綠攻擊 1×；藍／紅／綠打黃色為 0.5×。
- 兩人完成描寫後，主畫面會顯示兩個實際描出的字並自動碰撞。
- 每次碰撞基礎傷害 8 × 屬性倍率 × 完整度，戰力歸零即敗；最多 40 次碰撞避免無限對戰。
- 此版沿用 Firebase App Check / reCAPTCHA Enterprise 架構。
