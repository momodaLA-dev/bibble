# 和合本聖經問答競賽 v7（全平面檔案版）

這一版 **完全不使用任何資料夾**。所有檔案都放在 GitHub repository 根目錄。

## 上傳方式
把解壓縮後看到的所有檔案，一次全部上傳到 GitHub `bible` repository 的最外層。

不要再建立 `assets`、`questions`、`old`、`new` 等資料夾。

## 目前題庫
- `genesis.js`：創世記 120 題（簡單/普通/困難/上天堂各 30 題）
- `psalms.js`：詩篇示範題
- 其他經卷：已先建立空白 `.js` 題庫檔，之後可逐卷替換
- `questions.js`：總題庫索引，已連接 66 卷

## 之後新增題目
例如新增出埃及記：只要用新的 `exodus.js` 覆蓋 GitHub 根目錄同名檔案即可。
因為 `questions.js` 已經預先連接 66 卷，所以不需要再改總架構。

## 重要
不要把檔案重新放入資料夾，否則目前的相對路徑會失效。
